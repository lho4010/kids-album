방법 1) 파일 더블클릭
   📄 "앨범_시작.bat" 파일을 더블클릭하세요
   ✅ 자동으로 서버가 시작되고 브라우저가 열립니다

방법 2) 수동 실행
   1) start_server.bat 실행 → Python 서버 시작
   2) start_with_cloudflare.bat 실행 → 외부 접속 가능


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
📱 2. 접속하기
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

🖥️ 같은 PC에서 접속 (로컬)
   주소: http://localhost:8080/album.html


📱 모바일/외부에서 접속
   1) "외부접속_주소_확인.bat" 실행
   2) 또는 "Cloudflare Tunnel" 창에서 주소 확인
   3) https://...trycloudflare.com/album.html 형태
   
   ⚠️ 주의: 주소는 매번 바뀝니다!

⛔ 3. 서버 종료하기
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

   ✅ 모든 서버가 안전하게 종료됩니다


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
🔧 4. 문제 해결
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

❌ "포트가 이미 사용 중입니다" 에러
   → "앨범_종료.bat" 실행 후 다시 시작하세요

❌ 외부 접속이 안돼요 (Bad Gateway)
   → 서버를 종료하고 다시 시작하세요
   → 새로운 외부 접속 주소가 생성됩니다

❌ 사진이 안 보여요
   → 브라우저 새로고침 (F5 또는 Ctrl+R)
   → 캐시 삭제 후 다시 시도

❌ 느려요
   → 정상입니다. 이미지가 많아서 첫 로딩이 느릴 수 있습니다
   → 페이지별로 순차적으로 로드되므로 조금 기다려주세요

💡 5. 유용한 팁
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

✨ 목차 기능
   - 10개/20개/30개씩 페이지네이션
   - 이전/다음 버튼으로 목차 탐색
   - 원하는 날짜 클릭하면 자동으로 해당 글로 이동

✨ 사진 보기
   - 사진 클릭하면 크게 보기
   - ESC 키로 닫기
   - 화살표 키로 이전/다음 사진

✨ 키보드 단축키
   - ← → : 이전/다음 페이지
   - Home : 처음으로
   - End : 마지막으로
   - ESC : 라이트박스 닫기

✨ 모바일
   - 좌우 스와이프로 페이지 넘기기
   - 핀치 줌으로 확대/축소

⚠️ 외부 접속 주소는 매번 바뀝니다
